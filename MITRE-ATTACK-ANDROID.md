# MITRE ATT&CK for Android

APZ maps static findings to ATT&CK technique IDs as evidence.

Initial mappings:
- T1620 — Reflective Code Loading
- T1059.004 — Unix Shell
- T1547 — Boot or Logon Autostart Execution
- T1027 — Obfuscated/Compressed Files and Information
- T1071 — Application Layer Protocol

ATT&CK mappings are hypotheses/evidence tags, not proof that a technique was
executed. Dynamic sandbox evidence should increase confidence.
